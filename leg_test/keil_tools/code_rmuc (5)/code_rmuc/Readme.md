 4. **LQR参数调节**
 
      4.1
     （LQR的本质其实与PID很像，但也有所不同，LQR状态观测器中各个观测值的权重系数K都会对机体产生影响，而且LQR需要建立动力学模型，更吃模型一点。通俗来讲 PID就像一种很通用的，但LQR会更像是某个版本的T0英雄）  
  LQR的K矩阵是通过matlab拟合出来的，所以一定要确保你所用的matlab生成K矩阵代码中 各参数的准确性，该改的都要改。（转动惯量，机体质量，摆杆质量等）
  
     4.2 极性判断
   
     如果matlab没问题可以直接用， 那么就爽飞 >qwq<
   
     自己去判断进行可以选一个不是很离谱的值，一环一环的调节，确定好其中一个之后，再慢慢加 最终成一个完整的LQR  (很麻烦很浪费时间，但是当你需要判断某些观测值前系数符号是否反掉，就可以把其他的注释掉，保留相关的)
