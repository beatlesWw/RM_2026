一. 注意事项
1.本开源仅限于RoboMaster参赛队之间交流使用，不得用于任何商用行为。

3.本开源的最终解释权为中国石油大学（华东）RPS战队所有 。

二. 开源使用说明
本开源文件共包括“三维模型”、“说明文档”、“效果展示”三个文件夹。
1.三维模型：包含整车三维模型，总装文件为“UZ-05-open总装”，需使用SolidWorks2021及以上版本打开， 低版本或其他软件亦可打开同名称STEP文件。
2.说明文档：介绍该机器人机械结构设计思路与方案。
3.效果展示：包括“翻车自起.mp4”、“飞坡.mp4”、“跨越二级台阶.mp4”等视频，展示机器人的特色功能。
